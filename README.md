# ✦ Handful of Sparks

> *A quiet place to keep the images that move you.*

Handful of Sparks is a local-first image inspiration board for artists. Drag in the things that catch your eye — paintings, photographs, colour studies, textures, anything — tag them however makes sense to you, and find them again when you need them.

No cloud. No accounts. No algorithm deciding what you should find inspiring. Just you and your collection.

---

## What it does

- **Drag and drop** images straight onto the window to add them
- **Tag freely** — add as many or as few tags as you like to each image
- **Filter by tag** to pull up everything filed under a mood, a colour, an artist, a feeling
- **Browse in a grid** because inspiration should be something you can see all at once

That's it. That's the whole thing.

---

## What it doesn't do

- Sync to the cloud
- Organise into folders
- Sort your life out for you

---

## Stack

- [Tauri 2.x](https://tauri.app/) — Rust backend, tiny footprint
- React + TypeScript — frontend
- SQLite — local database, lives on your machine
- Tailwind CSS — styling

---

## Getting started

```bash
# Install dependencies
npm install

# Run in development
npm run tauri dev

# Build for production
npm run tauri build
```

---

## Why does this exist

Because hierarchical folders are a terrible way to store inspiration.

A painting isn't *in* one folder. It's warm-toned and melancholic and compositionally dense and reminds you of Klimt all at once. Tags let you find it from any of those angles. Folders make you pick one and forget the rest.

---

## Name

A handful of sparks — because that's what a good reference image is. Something small and flickering that you caught before it disappeared, kept somewhere safe to start a fire with later.
